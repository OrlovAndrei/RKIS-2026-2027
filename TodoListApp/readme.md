### Занятие 5:

1. Сделали безопасный ввод:
   * Заменили `Convert.ToInt32` на `int.TryParse`, номер задачи проверяется в отдельном методе `TryParseIndex` с параметром `out`.
   * Добавили проверки на `null` и пустой ввод, год рождения запрашивается повторно, если он введён неверно.
2. Доработали команду `add`:
   * `add "текст"` — добавление задачи в одну строку.
   * `add --multiline` / `add -m` — многострочный ввод, каждая строка вводится после `> `, ввод завершается строкой `!end`. Строки склеиваются через `\n` с помощью `StringBuilder`.
3. Доработали команду `view`:
   * По умолчанию выводится только текст задачи.
   * Флаги: `--index` (`-i`), `--status` (`-s`), `--update-date` (`-d`), `--all` (`-a`).
   * Короткие флаги можно объединять: `view -is`, `view -isd`.
   * Задачи выводятся таблицей с выравниванием колонок, текст обрезается до 30 символов и дополняется `...`.
4. Добавили команду `read <номер>` — показывает полный текст задачи, её статус и дату последнего изменения.
5. Обновили вывод команды `help`.
