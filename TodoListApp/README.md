TodoListApp

Консольное приложение для управления списком задач на C#.

Возможности

* help — показать список доступных команд.
* profile — вывести данные пользователя.
* add "текст" — добавить новую задачу.
* view — показать список задач, их статусы и даты изменений.
* done <индекс> — отметить задачу выполненной.
* delete <индекс> — удалить задачу.
* update <индекс> "текст" — изменить текст задачи.
* exit — завершить программу.

Особенности

* Задачи хранятся в массиве todos.
* Статусы выполнения хранятся в массиве statuses.
* Даты создания и последнего изменения хранятся в массиве dates.
* Все три массива расширяются синхронно.
* При изменении статуса или текста задачи обновляется дата.
* Индексация задач начинается с 0.

Пример использования

add "Купить хлеб"
add "Выполнить лабораторную"
view
done 0
update 1 "Завершить лабораторную"
delete 0
view
exit

Новые возможности (Лекция 5)
add:
  - --multiline или -m — многострочный ввод задачи (завершение по !end).
view:
  - --index или -i — показать ID задачи.
  - --status или -s — показать статус.
  - --update-date или -d — показать дату изменения.
  - --all или -a — показать все столбцы.
  - Вывод оформлен в виде таблицы. Текст обрезается до 30 символов.
read <idx>:
  - Выводит полный текст задачи по её ID, статус и дату изменения.

  ## Архитектура команд (паттерн «Команда»)

- `ICommand` — интерфейс с методом `Execute()`.
- Классы команд: `AddCommand`, `ViewCommand`, `ReadCommand`, `DoneCommand`,
  `UpdateCommand`, `DeleteCommand`, `ProfileCommand`, `HelpCommand`,
  `ExitCommand`, `UnknownCommand`.
- `CommandParser.Parse(input, todoList, profile)` разбирает строку пользователя,
  создаёт нужный объект команды и возвращает его как `ICommand`.
- Главный цикл: читает строку → `Parse` → `Execute`.

## Сохранение данных

Программа хранит данные в папке `data` рядом с исполняемым файлом:

- `profile.txt` — данные пользователя (имя, фамилия, год рождения).
- `todo.csv` — задачи в формате `Index;Text;IsDone;LastUpdate`
  (разделитель `;`, текст в кавычках, переносы строк записываются как `\n`).

За работу с файлами отвечает статический класс `FileManager`
(`EnsureDataDirectory`, `SaveProfile`, `LoadProfile`, `SaveTodos`, `LoadTodos`).
Пути формируются через `Path.Combine`, перед чтением выполняется проверка `File.Exists`.

При запуске данные загружаются автоматически, а после каждой команды,
изменяющей список задач (`add`, `done`, `update`, `delete`), список сохраняется.
Если файлов нет, они создаются при первом запуске.
