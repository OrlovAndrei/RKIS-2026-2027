Это простая консольная программа для управления списком задач. Приложение позволяет добавлять, просматривать, обновлять, удалять и отмечать задачи как выполненные. Поддерживает многострочные задачи и гибкие флаги для настройки вывода списка. Также программа запрашивает у пользователя ФИО и год рождения, чтобы отображать профиль с рассчитанным возрастом.
