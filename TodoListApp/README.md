TodoListApp

Консольное приложение для управления списком задач на C#.

Возможности

* help — показать список доступных команд.
* profile — вывести данные пользователя.
* add "текст" — добавить новую задачу.
* view — показать список задач.
* read <idx> — показать полную информацию о задаче.
* status <idx> <status> — изменить статус задачи.
* delete <idx> — удалить задачу.
* update <idx> "текст" — изменить текст задачи.
* exit — завершить программу.

Статусы задач

Каждая задача имеет один из пяти статусов:

* NotStarted — задача не начата.
* InProgress — задача выполняется.
* Completed — задача завершена.
* Postponed — задача отложена.
* Failed — задача не выполнена.

Примеры изменения статуса:

status 2 inprogress
status 1 completed
status 3 postponed

Возможности просмотра задач

Команда view поддерживает параметры:

* --index или -i — показать ID задачи.
* --status или -s — показать статус.
* --update-date или -d — показать дату изменения.
* --all или -a — показать все столбцы.

Вывод оформляется в виде таблицы. Текст задачи обрезается до 30 символов.

Дополнительные возможности

Команда add:

* --multiline или -m — многострочный ввод задачи. Завершение ввода обозначается !end.

Команда read <idx> выводит полный текст задачи, её статус и дату последнего изменения.

Архитектура

Для организации команд используется паттерн «Команда».

* ICommand — интерфейс с методом Execute().
* Классы команд: AddCommand, ViewCommand, ReadCommand, StatusCommand, UpdateCommand, DeleteCommand, ProfileCommand, HelpCommand, ExitCommand, UnknownCommand.
* CommandParser.Parse(input, todoList, profile) разбирает пользовательскую команду и создаёт соответствующий объект.
* Главный цикл программы считывает команду, передаёт её в CommandParser, а затем вызывает Execute().

Структура списка задач

Для хранения задач используется обобщённый список List<TodoItem>.

Класс TodoList содержит:

* закрытое поле списка задач;
* свойство Count;
* индексатор для доступа к задачам;
* метод SetStatus() для изменения статуса;
* итератор на основе yield return для перебора задач через foreach.

Класс TodoItem хранит текст задачи, её статус и дату последнего изменения.

Сохранение данных

Данные хранятся в папке data рядом с исполняемым файлом:

* profile.txt — информация о пользователе.
* todo.csv — список задач в формате CSV.

В CSV сохраняются индекс задачи, текст, статус и дата последнего изменения. Статус записывается строковым значением перечисления TodoStatus, например Completed.

За работу с файлами отвечает статический класс FileManager:

* EnsureDataDirectory();
* SaveProfile();
* LoadProfile();
* SaveTodos();
* LoadTodos().

При запуске приложения данные загружаются автоматически. После добавления, удаления, изменения текста или статуса задачи список сохраняется в файл.

Если файлы данных отсутствуют, они создаются при первом запуске программы.
