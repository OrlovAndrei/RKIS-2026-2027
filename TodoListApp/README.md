TodoListApp

Консольное приложение для управления списком задач на C#.

Возможности

* help — показать список доступных команд.
* profile — вывести данные пользователя.
* add "текст" — добавить новую задачу.
* view — показать список задач, их статусы и даты изменений.
* done <индекс> — отметить задачу выполненной.
* delete <индекс> — удалить задачу.
* update <индекс> "текст" — изменить текст задачи.
* exit — завершить программу.

Особенности

* Задачи хранятся в массиве todos.
* Статусы выполнения хранятся в массиве statuses.
* Даты создания и последнего изменения хранятся в массиве dates.
* Все три массива расширяются синхронно.
* При изменении статуса или текста задачи обновляется дата.
* Индексация задач начинается с 0.

Пример использования

add "Купить хлеб"
add "Выполнить лабораторную"
view
done 0
update 1 "Завершить лабораторную"
delete 0
view
exit

Новые возможности (Лекция 5)
add:
  - --multiline или -m — многострочный ввод задачи (завершение по !end).
view:
  - --index или -i — показать ID задачи.
  - --status или -s — показать статус.
  - --update-date или -d — показать дату изменения.
  - --all или -a — показать все столбцы.
  - Вывод оформлен в виде таблицы. Текст обрезается до 30 символов.
read <idx>:
  - Выводит полный текст задачи по её ID, статус и дату изменения.
