# TodoListApp

Консольное приложение на C# для практических заданий.

## Запуск

В терминале VS Code из корня репозитория:

    dotnet run --project TodoListApp

Для запуска нужен .NET SDK 10.0.

## Лекция 2

Программа спрашивает имя, фамилию и год рождения. Возраст считается как разница между текущим годом и годом рождения.

## Лекция 3

Задачи хранятся в массиве. В начале в нём две ячейки. Если места больше нет, программа создаёт массив вдвое длиннее и копирует туда задачи.

- `help` — показать команды.
- `profile` — показать имя, фамилию и год рождения.
- `add "текст задачи"` — добавить задачу.
- `view` — показать задачи.
- `exit` — выйти из программы.
