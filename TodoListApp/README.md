# TodoListApp

Учебное консольное приложение на C# (.NET 10) для хранения списка задач. Создано в рамках практических работ по Git, GitHub и основам C#. В последней версии команды реализованы по шаблону "Команда": каждая команда - отдельный класс с методом `Execute()`.

## Возможности

После ввода имени, фамилии и года рождения программа работает в бесконечном цикле и принимает команды:

- `help` - выводит список всех команд с кратким описанием;
- `profile` - выводит данные пользователя в формате `Имя Фамилия, возраст N`;
- `add "текст задачи"` - добавляет задачу в одну строку;
- `add --multiline` (или `add -m`) - многострочный режим: строки вводятся с приглашением `> `, ввод заканчивается строкой `!end`, строки сохраняются как один текст;
- `view` - выводит задачи в виде таблицы; по умолчанию показывается только текст задачи (первые 30 символов, остальное заменяется на `...`);
- `read <номер>` - выводит полный текст задачи, статус (`выполнена` / `не выполнена`) и дату последнего изменения;
- `done <номер>` - отмечает задачу выполненной и обновляет дату;
- `delete <номер>` - удаляет задачу, остальные сдвигаются на одну позицию влево;
- `update <номер> "новый текст"` - меняет текст задачи и обновляет дату;
- `exit` - завершает программу.

Номера задач считаются с единицы, как в выводе команды `view`. Неизвестные команды и неверный формат приводят к понятному сообщению об ошибке.

## Флаги команды view

Флаги можно комбинировать, короткие формы можно записывать слитно (`-is`):

- `--index`, `-i` - показать индекс задачи;
- `--status`, `-s` - показать статус задачи;
- `--update-date`, `-d` - показать дату последнего изменения;
- `--all`, `-a` - показать все данные одновременно.

Примеры:

```
view
view -i
view -is
view --index --status
view --all
```

## Структура программы

Каждый класс находится в отдельном файле, все поля классов закрыты (`private`), доступ к ним происходит через свойства и методы.

Данные:

- `TodoItem` - одна задача: `Text`, `IsDone`, `LastUpdate`, методы `MarkDone()`, `UpdateText()`, `GetShortInfo()`, `GetFullInfo()`;
- `TodoList` - список задач на закрытом массиве, который увеличивается в 2 раза при переполнении; методы `Add`, `Delete`, `GetItem`, `View`;
- `Profile` - данные пользователя, метод `GetInfo()`.

Команды (шаблон "Команда"):

- интерфейс `ICommand` с единственным методом `void Execute()`;
- классы команд `AddCommand`, `ViewCommand`, `ReadCommand`, `DoneCommand`, `DeleteCommand`, `UpdateCommand`, `ProfileCommand`, `HelpCommand`, `ExitCommand`, `ErrorCommand`;
- флаги команд хранятся как свойства `bool`, текст и индекс задачи как свойства `string` и `int`, а ссылки на `TodoList` и `Profile` присваиваются парсером;
- статический класс `CommandParser` с методом `Parse(string inputString, TodoList todoList, Profile profile)` определяет команду по строке, разбирает флаги и параметры, создаёт объект нужного класса и возвращает его как `ICommand`.

Главный цикл программы (`Program.cs`): считать строку, передать её в `CommandParser.Parse()` вместе с текущими `TodoList` и `Profile`, получить `ICommand` и вызвать `Execute()`.

## Запуск

Требуется установленный [.NET SDK 10.0](https://dotnet.microsoft.com/download).

Из командной строки, находясь в папке проекта (`TodoListApp`):

```
dotnet run
```

Из Visual Studio или JetBrains Rider: откройте файл `TodoListApp.csproj` и запустите проект (F5 / Run).
