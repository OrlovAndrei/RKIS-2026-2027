# Практическая работа №2 по C#

Геворгян Давид и Вадим Шкутко, группа 3833.

`TodoListApp` — консольное приложение, которое запрашивает имя, фамилию и год рождения. Программа проверяет ввод, вычисляет возраст по разнице между текущим годом и годом рождения и выводит данные пользователя.

Для запуска откройте `TodoListApp.csproj` в Visual Studio или Rider либо выполните команду из папки проекта при установленном .NET SDK 8:

```sh
dotnet run --project TodoListApp.csproj
```
