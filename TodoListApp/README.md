# TodoListApp

Учебное консольное приложение на C# (.NET 10) для хранения списка задач. Создано в рамках практических работ по Git, GitHub и основам C#. Команды реализованы по шаблону "Команда", данные сохраняются в файлы и восстанавливаются при запуске, у задач есть статусы.

## Возможности

При первом запуске программа спрашивает имя, фамилию и год рождения и сохраняет их. При следующих запусках профиль и задачи загружаются из файлов автоматически. Дальше программа работает в бесконечном цикле и принимает команды:

- `help` - выводит список всех команд с кратким описанием;
- `profile` - выводит данные пользователя в формате `Имя Фамилия, возраст N`;
- `add "текст задачи"` - добавляет задачу в одну строку (статус `не начато`);
- `add --multiline` (или `add -m`) - многострочный режим: строки вводятся с приглашением `> `, ввод заканчивается строкой `!end`, строки сохраняются как один текст;
- `view` - выводит задачи в виде таблицы; по умолчанию показывается только текст задачи (первые 30 символов, остальное заменяется на `...`);
- `read <номер>` - выводит полный текст задачи, статус и дату последнего изменения;
- `status <номер> <статус>` - меняет статус задачи и обновляет дату;
- `delete <номер>` - удаляет задачу, остальные сдвигаются на одну позицию влево;
- `update <номер> "новый текст"` - меняет текст задачи и обновляет дату;
- `exit` - завершает программу.

Номера задач считаются с единицы, как в выводе команды `view`. Неизвестные команды и неверный формат приводят к понятному сообщению об ошибке.

## Статусы задач

Статус хранится в перечислении `TodoStatus`. В команде `status` его можно писать в любом регистре:

| Значение в команде | Название в программе |
| --- | --- |
| `notstarted` | не начато |
| `inprogress` | в процессе |
| `completed` | выполнено |
| `postponed` | отложено |
| `failed` | провалено |

Примеры:

```
status 2 inprogress
status 1 completed
```

Старая команда `done` удалена: вместо неё используется `status <номер> completed`.

## Флаги команды view

Флаги можно комбинировать, короткие формы можно записывать слитно (`-is`):

- `--index`, `-i` - показать индекс задачи;
- `--status`, `-s` - показать статус задачи (текстом, например `в процессе`);
- `--update-date`, `-d` - показать дату последнего изменения;
- `--all`, `-a` - показать все данные одновременно.

Примеры:

```
view
view -i
view -is
view --index --status
view --all
```

## Сохранение данных

Работой с файлами занимается статический класс `FileManager` (классы `File`, `Directory`, `Path`):

- `EnsureDataDirectory` - создаёт папку `data`, если её нет;
- `SaveProfile` и `LoadProfile` - сохраняют и загружают данные пользователя в `profile.txt` (три строки: имя, фамилия, год рождения);
- `SaveTodos` и `LoadTodos` - сохраняют и загружают задачи в `todo.csv`.

Папка `data` создаётся рядом с собранной программой (`bin/Debug/net10.0/data`), поэтому личные данные не попадают в репозиторий. После каждой команды, которая меняет список задач (`add`, `status`, `delete`, `update`), список сразу сохраняется в файл.

Формат `todo.csv` (разделитель `;`). Статус записывается через `ToString()`, а при загрузке преобразуется обратно через `Enum.Parse<TodoStatus>()`:

```
Index;Text;Status;LastUpdate
0;"Купить продукты";NotStarted;2025-08-21T14:30:00
1;"Сделать домашку";Completed;2025-08-20T10:00:00
```

Текст задачи берётся в кавычки, перенос строки в тексте записывается как `\n`, а при чтении преобразуется обратно. Файлы старого формата (где вместо статуса стояло `true` или `false`) тоже загружаются: `true` превращается в `Completed`, `false` в `NotStarted`.

## Структура программы

Каждый класс находится в отдельном файле, все поля классов закрыты (`private`), доступ к ним происходит через свойства и методы.

Данные:

- `TodoStatus` - перечисление статусов задачи;
- `TodoItem` - одна задача: `Text`, `Status`, `LastUpdate`, методы `SetStatus()`, `UpdateText()`, `GetShortInfo()`, `GetFullInfo()`;
- `TodoList` - список задач на закрытом `List<TodoItem>`; индексатор для доступа к задаче по индексу, метод-итератор с `yield return` (задачи можно перебирать через `foreach`), методы `Add`, `Delete`, `SetStatus`, `View`;
- `Profile` - данные пользователя, метод `GetInfo()`;
- `FileManager` - статический класс для работы с файлами и папками.

Команды (шаблон "Команда"):

- интерфейс `ICommand` с единственным методом `void Execute()`;
- классы команд `AddCommand`, `ViewCommand`, `ReadCommand`, `StatusCommand`, `DeleteCommand`, `UpdateCommand`, `ProfileCommand`, `HelpCommand`, `ExitCommand`, `ErrorCommand`;
- статический класс `CommandParser` с методом `Parse(string inputString, TodoList todoList, Profile profile)` определяет команду по строке, разбирает флаги и параметры (в том числе строку статуса преобразует в `TodoStatus`), создаёт объект нужного класса и возвращает его как `ICommand`.

Главный цикл программы (`Program.cs`): загрузить профиль и задачи, затем считать строку, передать её в `CommandParser.Parse()`, получить `ICommand` и вызвать `Execute()`.

## Запуск

Требуется установленный [.NET SDK 10.0](https://dotnet.microsoft.com/download).

Из командной строки, находясь в папке проекта (`TodoListApp`):

```
dotnet run
```

Из Visual Studio или JetBrains Rider: откройте файл `TodoListApp.csproj` и запустите проект (F5 / Run).
