# Лабораторная 1 — Git и GitHub

Практическое задание находится в [лекции 1](../Лекции/Семестр%201%20Лекция%201.pdf). Выполняйте Git-эксперимент в отдельной временной папке, чтобы не перепутать учебные коммиты с историей основного проекта.

## Локальная часть

1. Создайте два текстовых файла, добавьте их и выполните первый коммит.
2. Добавьте `.gitignore`, внесите изменение в отслеживаемый файл и сделайте следующий коммит.
3. Создайте ветку, измените второй файл и зафиксируйте изменение.
4. Слейте ветку в основную fast-forward-слиянием.
5. Создайте коммиты в обеих ветках, изменив одну и ту же строку, выполните слияние, разрешите конфликт и завершите слияние коммитом.
6. Проверьте историю командой `git log --oneline --graph --all`.

Пример начальных команд в новой папке:

```powershell
git init
git add .
git commit -m "lesson 1: initial files"
git switch -c feature/lesson-1
```

## GitHub и отчёт

- Сделайте форк репозитория курса, добавьте напарника в Collaborators и клонируйте свой форк.
- Отправьте коммиты в свой форк, создайте там README и выполните `git pull`, чтобы забрать его локально.
- Создайте Pull Request по формату `Фамилия1 Фамилия2 номер_группы`.
- Сделайте скриншоты шагов, соберите их по порядку в один PDF и добавьте PDF в свой репозиторий.

Форк, приглашение напарника, публикацию PR и скриншоты нельзя выполнить только изменением локальных файлов; выполните эти действия в своём аккаунте GitHub.
