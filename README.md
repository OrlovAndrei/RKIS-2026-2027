## Работа № 3. TodoList

### Описание проекта

TodoList — консольное приложение на C# для управления списком задач с помощью текстовых команд.

### Реализованные возможности

- Ввод имени, фамилии и года рождения пользователя при запуске.

- Непрерывная работа программы до ввода команды `exit`.

- Хранение задач в массиве `todos`, рассчитанном изначально на два элемента.

- Автоматическое увеличение размера массива в два раза при заполнении.

- Копирование существующих задач в новый массив при расширении.

### Доступные команды

| Команда | Описание |

|---|---|

| `help` | Вывод списка доступных команд |

| `profile` | Просмотр имени, фамилии и года рождения пользователя |

| `add "текст"` | Добавление задачи |

| `view` | Просмотр списка задач |

| `exit` | Завершение работы программы |

### Пример работы

```text

> add "Купить молоко"

Задача добавлена

> view

1. Купить молоко

> exit

Завершение работы

```

## Задание № 6. Объектно-ориентированное программирование

### Описание проекта

Выполнен переход от процедурного стиля программирования к объектно-ориентированному. Логика работы с задачами, списком задач и данными пользователя разделена между тремя классами: `TodoItem`, `TodoList` и `Profile`.

Каждый класс размещён в отдельном файле. Поля классов закрыты модификатором `private`, а доступ к данным осуществляется через свойства и методы.

### Структура проекта

| Файл | Назначение |

|---|---|

| `Program.cs` | Ввод данных, обработка команд и взаимодействие классов |

| `TodoItem.cs` | Хранение информации об отдельной задаче |

| `TodoList.cs` | Управление списком задач |

| `Profile.cs` | Хранение данных пользователя |

### Класс TodoItem

Класс представляет отдельную задачу и содержит следующие свойства:

- `Text` — текст задачи.

- `IsDone` — статус выполнения.

- `LastUpdate` — дата создания или последнего изменения.

Конструктор принимает текст задачи, устанавливает статус `IsDone = false` и сохраняет текущее время в `LastUpdate`.

**Основные методы:**

| Метод | Назначение |

|---|---|

| `MarkDone()` | Отмечает задачу выполненной и обновляет дату изменения |

| `UpdateText(string newText)` | Изменяет текст задачи и обновляет дату |

| `GetShortInfo()` | Возвращает краткую информацию: текст длиной до 30 символов, статус и дату |

| `GetFullInfo()` | Возвращает полный текст задачи, статус и дату последнего изменения |

### Класс TodoList

Класс отвечает за управление списком задач. Для хранения объектов используется приватный массив `TodoItem[]`.

**Основные методы:**

| Метод | Назначение |

|---|---|

| `Add(TodoItem item)` | Добавляет задачу в список |

| `Delete(int index)` | Удаляет задачу и сдвигает оставшиеся элементы |

| `View(bool showIndex, bool showDone, bool showDate)` | Выводит таблицу задач с учётом выбранных столбцов |

| `GetItem(int index)` | Возвращает задачу по её номеру |

| `IncreaseArray(TodoItem[] items, TodoItem item)` | Приватный метод увеличения массива в два раза при заполнении |

### Класс Profile

Класс предназначен для хранения информации о пользователе.

**Свойства:**

- `FirstName` — имя.

- `LastName` — фамилия.

- `BirthYear` — год рождения.

Метод `GetInfo()` формирует строку с именем, фамилией и возрастом пользователя. Он используется при выполнении команды `profile`.

### Взаимодействие команд с классами

| Команда | Реализация |

|---|---|

| `add` | Создаёт объект `TodoItem` и передаёт его в `TodoList.Add()` |

| `done <номер>` | Получает задачу через `GetItem()` и вызывает `MarkDone()` |

| `update <номер> "новый текст"` | Получает задачу через `GetItem()` и вызывает `UpdateText()` |

| `view` | Вызывает `TodoList.View()` с параметрами отображения |

| `read <номер>` | Получает задачу через `GetItem()` и вызывает `GetFullInfo()` |

| `delete <номер>` | Вызывает `TodoList.Delete()` |

| `profile` | Выводит данные через `Profile.GetInfo()` |

## Задание № 7. Интерфейс ICommand и паттерн «Команда»

### Цель работы

Переработать обработку пользовательских команд с использованием интерфейса `ICommand` и паттерна проектирования «Команда».

### Описание выполненных изменений

Логика выполнения команд разделена на отдельные классы. Интерфейс `ICommand` задаёт общий метод `Execute()`, который реализуется каждой командой. Разбор введённой пользователем строки вынесен в статический класс `CommandParser`.

### Реализованные возможности

- Создан интерфейс `ICommand` с методом `Execute()`.
- Реализованы отдельные классы команд для добавления, просмотра, изменения, удаления и выполнения задач.
- Добавлены команды для просмотра полной информации о задаче и данных пользователя.
- Параметры команд и флаги хранятся в свойствах соответствующих классов.
- Создан класс `CommandParser` для определения команды, разбора флагов и параметров и создания объекта команды.
- Основной цикл программы передаёт введённую строку в `CommandParser.Parse()`, а затем вызывает `Execute()` у полученной команды.

### Структура проекта

| Файл | Назначение |
|---|---|
| `Program.cs` | Основной цикл программы и взаимодействие с пользователем. |
| `ICommand.cs` | Интерфейс с методом `Execute()`. |
| `CommandParser.cs` | Разбор строки и создание объекта нужной команды. |
| `AddCommand.cs` | Добавление обычной или многострочной задачи. |
| `ViewCommand.cs` | Просмотр списка задач с выбранными столбцами. |
| `DoneCommand.cs` | Отметка задачи как выполненной. |
| `UpdateCommand.cs` | Изменение текста задачи. |
| `DeleteCommand.cs` | Удаление задачи. |
| `ReadCommand.cs` | Просмотр полной информации о задаче. |
| `ProfileCommand.cs` | Вывод информации о пользователе. |
| `TodoItem.cs` | Хранение данных отдельной задачи. |
| `TodoList.cs` | Управление списком задач. |
| `Profile.cs` | Хранение данных пользователя. |

### Примеры команд

| Команда | Описание |
|---|---|
| `help` | Вывод справки по командам. |
| `profile` | Просмотр данных пользователя. |
| `add "Купить продукты"` | Добавление задачи. |
| `add --multiline` или `add -m` | Добавление многострочной задачи; ввод завершается строкой `!end`. |
| `view` | Просмотр списка задач. |
| `view --all` или `view -a` | Просмотр всех столбцов. |
| `done 1` | Отметить задачу № 1 выполненной. |
| `update 1 "Новый текст"` | Изменить текст задачи № 1. |
| `delete 1` | Удалить задачу № 1. |
| `read 1` | Просмотреть полную информацию о задаче № 1. |
| `exit` | Завершить программу. |

### Принцип работы

При вводе команды `CommandParser.Parse()` определяет её название, разбирает параметры и флаги, создаёт соответствующий объект и возвращает его через интерфейс `ICommand`. Затем основной цикл вызывает `Execute()`, а команда выполняет необходимое действие с объектом `TodoList` или `Profile`.

Такое разделение позволяет отделить разбор пользовательского ввода от выполнения операций и упрощает расширение приложения новыми командами.

### Результат работы

В рамках задания обработка команд организуется с использованием интерфейса `ICommand` и паттерна «Команда». Каждая операция вынесена в отдельный класс, а создание команд по введённой строке выполняет `CommandParser`.
