### Занятие 2:

1. Создан форк репозитория и настроен совместный доступ (Collaborators).
2. Создано консольное приложение `TodoListApp` на платформе .NET.
3. Настроен файл `.gitignore` для исключения служебных папок `bin`, `obj`, `.vs`.
4. Реализована программа, которая принимает имя, фамилию и год рождения пользователя, после чего рассчитывает его текущий возраст и выводит результат в консоль.

### Занятие 3:

1. Создан массив строк `todos` начальной длины 2 для хранения задач.
2. Реализован бесконечный цикл `while (true)` для непрерывной обработки команд пользователя.
3. Реализованы команды:
   * `help` — вывод списка доступных команд.
   * `profile` — вывод данных пользователя в формате `<Имя> <Фамилия>, <Год рождения>`.
   * `add "текст"` — добавление новой задачи с извлечением текста через `String.Split`.
   * `view` — вывод всех непустых задач из массива через цикл `for`.
   * `exit` — завершение работы программы.
4. Реализован алгоритм динамического расширения массива: при заполнении создается массив в 2 раза больше и элементы копируются циклом `for`.

### Занятие 4:

1. Сделали рефакторинг кода:
   * Обернули всё в класс `Program` и заменили магическое число размера массива на константу `InitialCapacity = 2`.
   * Вынесли логику из `Main` в отдельные понятные методы: для каждой команды, шапки, регистрации пользователя и расширения массивов.
2. Добавили два новых массива параллельно к `todos`:
   * `statuses` (`bool[]`) — хранит статус задачи (сделана / не сделана).
   * `dates` (`DateTime[]`) — сохраняет дату создания или последнего изменения задачи.
3. В методе `ResizeArrays` настроили синхронное удвоение сразу всех трех массивов при их заполнении.
4. Обновили работу старых команд:
   * `add` — теперь при создании задачи сразу пишет статус `false` и текущее время (`DateTime.Now`).
   * `view` — теперь показывает задачу со статусом выполнения и датой.
5. Реализовали новые команды (каждую вынесли в свой метод):
   * `done <номер>` — помечает задачу выполненной и обновляет время изменения.
   * `delete <номер>` — удаляет задачу по номеру со сдвигом элементов массива влево.
   * `update <номер> "текст"` — перезаписывает текст задачи и обновляет дату.

### Занятие 5:

1. Сделали безопасный ввод:
   * Заменили `Convert.ToInt32` на `int.TryParse`, номер задачи проверяется в отдельном методе `TryParseIndex` с параметром `out`.
   * Добавили проверки на `null` и пустой ввод, год рождения запрашивается повторно, если он введён неверно.
2. Доработали команду `add`:
   * `add "текст"` — добавление задачи в одну строку.
   * `add --multiline` / `add -m` — многострочный ввод, каждая строка вводится после `> `, ввод завершается строкой `!end`. Строки склеиваются через `\n` с помощью `StringBuilder`.
3. Доработали команду `view`:
   * По умолчанию выводится только текст задачи.
   * Флаги: `--index` (`-i`), `--status` (`-s`), `--update-date` (`-d`), `--all` (`-a`).
   * Короткие флаги можно объединять: `view -is`, `view -isd`.
   * Задачи выводятся таблицей с выравниванием колонок, текст обрезается до 30 символов и дополняется `...`.
4. Добавили команду `read <номер>` — показывает полный текст задачи, её статус и дату последнего изменения.
5. Обновили вывод команды `help`.

### Занятие 6:

1. Переписали программу в объектно-ориентированном стиле, вместо параллельных массивов `todos`, `statuses`, `dates` теперь используются классы.
2. Создали класс `TodoItem` (файл `TodoItem.cs`):
   * Свойства `Text`, `IsDone`, `LastUpdate`, изменить их можно только через методы класса.
   * Конструктор принимает текст задачи, `IsDone = false`, `LastUpdate = DateTime.Now`.
   * Методы `MarkDone()`, `UpdateText()`, `GetShortInfo()`, `GetFullInfo()`.
3. Создали класс `TodoList` (файл `TodoList.cs`):
   * Приватное поле — массив задач `TodoItem[]`.
   * Методы `Add()`, `Delete()`, `View()`, `GetItem()`.
   * Приватный метод `IncreaseArray()` увеличивает массив в 2 раза при переполнении.
4. Создали класс `Profile` (файл `Profile.cs`) со свойствами `FirstName`, `LastName`, `BirthYear` и методом `GetInfo()`, который возвращает строку `"Имя Фамилия, возраст N"`.
5. Изменили логику команд:
   * `add` создаёт объект `TodoItem` и добавляет его в `TodoList`.
   * `done`, `update`, `read` получают задачу через `GetItem()` и вызывают `MarkDone()`, `UpdateText()`, `GetFullInfo()`.
   * `view` вызывает метод `View()` и выводит таблицу.
   * `profile` выводит данные через `Profile.GetInfo()`.
