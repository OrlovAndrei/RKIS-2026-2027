Создали консольное приложение TodoListApp (C#, Visual Studio):
Попросили пользователя ввести имя, фамилию и год рождения.
Получили введённые пользователем значения и  записали их в соответствующие переменные.
Перевели год рождения в целое число и вычли его из текущего года, чтобы получить возраст.
Вывели сообщение вида: Добавлен пользователь <Имя> <Фамилия>, возраст - <возраст>.
