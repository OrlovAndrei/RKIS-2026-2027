## Лабораторная работа №2
Создано консольное приложение TodoListApp, добавлен вывод авторов и расчет возраста пользователя.
## Лабораторная работа №3
Добавлены команды:
- help (вывод списка доступных команд)
- profile (вывод информации о пользователе)
- add (добавление новой задачи в массив с автоматическим расширением в 2 раза при заполнении)
- view (отображение нумерованного списка текущих задач)
- exit (корректное завершение работы)
## Лабораторная работа №4
Проведен рефакторинг кода, добавлены новые массивы для хранения статусов и дат. 
Добавлены и обновлены команды:
- add (теперь дополнительно записывает статус "не сделано" и текущую дату)
- view (теперь выводит статус выполнения и дату создания/изменения)
- done (отметка задачи как выполненной со сменой статуса и обновлением даты)
- delete (удаление задачи со сдвигом элементов массива)
- update (обновление текста задачи с записью новой даты)
