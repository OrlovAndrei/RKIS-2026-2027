# TodoListApp

Консольный список задач на C#/.NET 8. Проект развивается по практическим заданиям из лекций семестра 1 и хранит задачи отдельно для каждого профиля.

## Возможности

- Регистрация и вход по логину и паролю; у каждого пользователя свой профиль и отдельный список задач.
- Добавление однострочных и многострочных задач.
- Табличный просмотр с флагами, полный просмотр, поиск, фильтрация статистики.
- Редактирование, удаление, изменение статуса; отмена и повтор последних изменений.
- Автоматическое сохранение данных в CSV при изменениях и восстановление при запуске.
- Пароли хранятся как PBKDF2-хеши, а не в открытом виде.

## Запуск

```powershell
dotnet run --project TodoListApp/TodoListApp/TodoListApp.csproj
```

Файлы `profile.csv` и `todos_<Id>.csv` создаются в `TodoListApp/TodoListApp/user-data/`. Эта папка исключена из Git, поскольку содержит локальные пользовательские данные.

## Команды

- `help` — справка.
- `profile` — профиль; `profile --out` или `profile -o` — выйти из профиля.
- `add "текст задачи"` — добавить задачу.
- `add --multiline` или `add -m` — ввести многострочную задачу; завершить строкой `!end`.
- `view` — показать только текст задач.
- `view -i`, `view -s`, `view -d` — добавить к таблице ID, статус или дату изменения; флаги можно объединять, например `view -isd`.
- `view -a` или `view --all` — все колонки.
- `read <id>` — полный текст и сведения о задаче.
- `status <id> <статус>` — статус `NotStarted`, `InProgress`, `Completed`, `Postponed` или `Failed`.
- `update <id> "новый текст"` — изменить задачу.
- `delete <id>` — удалить задачу.
- `search <текст> [-p]` — поиск по фрагменту; `-p` ищет только совпадения в начале строки.
- `stats` — количество задач по статусам.
- `undo` / `redo` — отменить / повторить изменение.
- `types` / `collections` — примеры struct, record, boxing/unboxing и структур данных.
- `exit` — завершить приложение.
