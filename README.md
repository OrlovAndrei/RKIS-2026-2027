# Практическое задание: TodoListApp

**Выполнили:** Кудрявцев Всеволод, Гапченко Денис (Группа 2121)

## Что сделано:
- Создано консольное приложение на C# (TodoListApp).
- Настроен файл .gitignore для исключения папок bin, obj, .vs.
- Реализован ввод имени, фамилии и года рождения пользователя.
- Выполнен расчет возраста на основе текущего года и вывод сообщения в консоль.
- Изменен приветственный текст.

## Новые возможности:
- Добавлен бесконечный цикл, в котором программа принимает команды пользователя.
- Команда help выводит список всех доступных команд.
- Команда profile выводит имя, фамилию и год рождения пользователя.
- Команда add "текст задачи" добавляет новую задачу в массив todos.
- Команда view выводит все непустые задачи из массива.
- Команда exit завершает работу программы.
- Реализовано расширение массива todos: если места не хватает, создаётся новый массив в 2 раза длиннее, и в него копируются старые задачи.
