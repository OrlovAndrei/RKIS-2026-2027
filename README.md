## Практическое задание — TodoListApp

Работу выполнили Капинус Илья Алексеевич и Халлыев Тимур Константинович.

Консольное приложение `TodoListApp` запрашивает имя, фамилию и год рождения, вычисляет возраст по текущему году и выводит данные пользователя.

Запуск: `dotnet run --project TodoListApp/TodoListApp.csproj`.

## Возможности TodoListApp после занятия 3

При запуске приложение запрашивает имя, фамилию и год рождения пользователя.

Доступные команды:

- `help` - вывести список доступных команд.
- `profile` - вывести профиль в формате `Имя Фамилия, Год рождения`.
- `add "текст задачи"` - добавить задачу в массив.
- `view` - вывести непустые задачи.
- `exit` - завершить работу приложения.

Массив задач создаётся с начальной длиной 2 элемента. При заполнении массива его размер автоматически увеличивается в два раза, а существующие задачи сохраняются.

## Возможности TodoListApp после занятия 4

- Команды вынесены в отдельные методы.
- Для каждой задачи хранятся текст, статус выполнения и дата последнего изменения.
- Массивы `todos`, `statuses` и `dates` синхронно расширяются при нехватке места.
- `done <idx>` отмечает задачу с указанным индексом выполненной.
- `delete <idx>` удаляет задачу и сдвигает следующие элементы массивов влево.
- `update <idx> "новый текст"` обновляет текст задачи.
- `view` показывает индекс, текст, статус и дату в формате `dd.MM.yyyy HH:mm`.

## Возможности TodoListApp после занятия 5

- `add "текст задачи"` добавляет однострочную задачу.
- `add --multiline` (также `add --multi-line` или `add -m`) включает ввод многострочной задачи. Строка `!end` завершает ввод, строки сохраняются вместе.
- `view` показывает только тексты задач. Флаги `-i` / `--index`, `-s` / `--status` и `-d` / `--update-date` включают дополнительные столбцы; `-a` / `--all` включает их все. Короткие флаги можно объединять, например `view -is`.
- Вывод `view` оформлен таблицей; длинный текст обрезается до 30 символов с многоточием.
- `read <idx>` выводит полный текст задачи, статус и дату последнего изменения.

## Возможности TodoListApp после занятия 6

Логика приложения организована в объектно-ориентированном стиле:

- `TodoItem` хранит текст задачи, её статус и дату последнего изменения; предоставляет методы для выполнения, обновления текста и получения краткой или полной информации.
- `TodoList` управляет массивом объектов `TodoItem`, добавлением, удалением, поиском и табличным выводом задач.
- `Profile` хранит имя, фамилию и год рождения и формирует информацию о пользователе для команды `profile`.

Каждый класс расположен в отдельном файле в папке `TodoListApp`.
