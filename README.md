# TodoListApp

Консольное приложение на C# для управления списком задач.  
Работу выполнили: Козлов и Голубев.

- Ввод данных пользователя (имя, фамилия, год рождения) и расчёт возраста.
- Интерактивный режим работы через консольные команды в бесконечном цикле.
- Хранение задач в массиве `todos` с автоматическим динамическим расширением в 2 раза при заполнении.
