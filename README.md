
# .:| TodoListApp |:.

## .:| Описание |:.
Консольное приложение на C#.

## .:| Функциональность |:.
- Сохранение имени, фамилии и года рождения пользователя.
- Просмотр профиля пользователя.
- Добавление новых задач.
- Просмотр списка задач.
- Команды управления через консоль.
- Автоматическое увеличение размера массива при заполнении.
- Выход из программы.

## .:| Команды |:.
- `help` — список команд.
- `profile` — информация о пользователе.
- `add <текст>` — добавление задачи.
- `view` — просмотр задач.
- `exit` — завершение программы.
