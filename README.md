# TodoList (Практическое задание #3,4)

## Реализованный функционал:
Программа представляет собой консольный менеджер задач с интерактивным вводом данных пользователя.
Каждая задача теперь хранит не только текст, но и свой статус (выполнена/не выполнена) и дату создания/изменения. Все массивы расширяются синхронно.

Поддерживаются следующие команды:
* `help` — выводит список доступных команд.
* `profile` — выводит данные пользователя, введенные при запуске (Имя, Фамилия, Год рождения).
* `add "текст задачи"` — добавляет новую задачу в массив. Если массив заполнен, он автоматически расширяется в 2 раза.
* `view` — выводит список всех добавленных задач.
* `done <idx>` — отмечает задачу под указанным номером как выполненную и обновляет дату изменения.
* `delete <idx>` — удаляет задачу по номеру. Все оставшиеся задачи, статусы и даты сдвигаются влево.
* `update <idx> "новый текст"` — заменяет текст задачи под указанным номером и обновляет дату изменения.
* `exit` — завершает работу программы.

# TodoList (Практическое задание № 5)

## Новые возможности (Флаги и команды)

Программа была расширена поддержкой консольных флагов и новыми командами.

### 1. Команда `add`
* `add "текст"` — обычное добавление задачи (в одну строку).
* `add -m` или `add --multiline` — **многострочный режим**. Программа будет запрашивать строки до тех пор, пока вы не введете `! end` (или `!end`). Все строки сохранятся в одну задачу с переносами.

### 2. Команда `view` (табличный вывод)
Выводит задачи в виде аккуратной таблицы. Текст задачи обрезается до 30 символов (вместо остального ставится `...`). Поддерживает флаги, которые можно комбинировать:
* `view -i` или `view --index` — показать колонку с номерами задач.
* `view -s` или `view --status` — показать колонку со статусом (сделано/не сделано).
* `view -d` или `view --update-date` — показать колонку с датой изменения.
* `view -a` или `view --all` — показать сразу все колонки.
* *Пример комбинации:* `view -is` или `view -i -s` (выведет номер и статус).

### 3. Команда `read <idx>`
Позволяет прочитать полный текст задачи (без обрезки), а также узнать её актуальный статус и дату последнего изменения.
* *Пример:* `read 2`

### 4. Обновленная справка
Команда `help` теперь содержит описание всех новых флагов и команд, чтобы не приходилось вспоминать их наизусть.

# TodoList (Практическое задание № 6)

## Перевод проекта на ООП (Объектно-ориентированное программирование)

Программа была полностью переписана с процедурного стиля на объектно-ориентированный. Теперь весь код разделен на логические сущности (классы), каждая из которых отвечает за свою зону ответственности.

### Реализованные классы:

1. **`TodoItem` (Задача)**
   - Хранит текст задачи, статус выполнения и дату последнего изменения.
   - Использует **инкапсуляцию**: поля скрыты (`private`), доступ к ним осуществляется через свойства только для чтения.
   - Содержит методы `MarkDone()` и `UpdateText()` для безопасного изменения состояния, а также методы `GetShortInfo()` и `GetFullInfo()` для вывода.

2. **`TodoList` (Список задач)**
   - Управляет массивом задач (скрыт внутри класса как `private TodoItem[] _items`).
   - Отвечает за добавление, удаление задач и их вывод в виде таблицы.
   - Включает приватный метод `IncreaseArray()`, который автоматически расширяет массив при его переполнении.

3. **`Profile` (Пользователь)**
   - Хранит имя, фамилию и год рождения.
   - Метод `GetInfo()` автоматически вычисляет возраст и возвращает строку с данными пользователя.

4. **`Program` (Точка входа)**
   - Главный файл программы. Больше не хранит данные в массивах, а лишь принимает команды от пользователя и вызывает соответствующие методы у созданных объектов.
