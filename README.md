## Практическое задание №3 — Ветвления и циклы

В приложении TodoListApp реализована работа со списком задач с использованием массивов, условий и циклов.

### Доступные команды

- `help` — выводит список команд.
- `profile` — показывает имя, фамилию и год рождения пользователя.
- `add "текст задачи"` — добавляет новую задачу.
- `view` — показывает все добавленные задачи.
- `exit` — завершает программу.

### Работа с массивом

Для хранения задач используется массив `string[] todos`.

Начальная длина массива — 2 элемента. Когда массив заполняется, создаётся новый массив в два раза больше. Старые задачи переносятся в него с помощью цикла `for`.

### Запуск программы

Для запуска необходимо перейти в папку TodoListApp и выполнить команду:

`dotnet run`

### Результат

Реализованы все пять команд, добавление задач, расширение массива и вывод списка задач.

## Практическое задание №6 — Введение в ООП

Приложение **TodoListApp** переведено с трёх параллельных массивов на объектно-ориентированную структуру.

### Новые классы

- `TodoItem.cs` — одна задача: свойства `Text`, `IsDone`, `LastUpdate`; методы `MarkDone()`, `UpdateText()`, `GetShortInfo()`, `GetFullInfo()`.
- `TodoList.cs` — хранит приватный массив объектов `TodoItem`, добавляет, удаляет и выводит задачи. При заполнении массив увеличивается в два раза внутренним методом `IncreaseArray()`.
- `Profile.cs` — хранит имя, фамилию и год рождения; метод `GetInfo()` возвращает имя, фамилию и возраст.
- `Program.cs` — обработка команд и пользовательского ввода с использованием созданных объектов.

Поля скрыты внутри классов, а изменение данных происходит через свойства и методы. Вместо отдельных массивов `todos`, `statuses`, `dates` используется **один массив объектов задач**.

### Поддерживаемые команды

- `help` — список команд;
- `profile` — имя, фамилия, возраст;
- `add "текст"` — добавить обычную задачу;
- `add -m` / `add --multiline` — добавить многострочную задачу (завершение `!end`);
- `view` — таблица с текстом задач;
- `view -i`, `view -s`, `view -d`, `view -is`, `view -a` — настройка колонок;
- `read 1` — полный текст задачи со статусом и датой;
- `done 1` — отметить задачу выполненной;
- `update 1 "новый текст"` — изменить задачу;
- `delete 1` — удалить задачу;
- `exit` — завершить приложение.

### Запуск

```bash
cd TodoListApp
dotnet run
```

### Проверка

Проверены добавление обычных и многострочных задач, вывод таблицы с флагами, просмотр полного текста, смена статуса, изменение текста и удаление задачи. Проводилась проверка неверного номера задачи (`read 99`, `done 99`).

## Практическое задание №8 — Работа с файлами

В `TodoListApp` добавлено сохранение данных между запусками программы.

### Что изменилось

- Создан статический класс `FileManager` с методами `EnsureDataDirectory`, `SaveProfile`, `LoadProfile`, `SaveTodos`, `LoadTodos`.
- В папке `TodoListApp/data` создаются `profile.txt` и `todo.csv`.
- Профиль вводится один раз и автоматически загружается при следующих запусках.
- Задачи сохраняются в CSV с колонками `Index;Text;IsDone;LastUpdate`.
- Команды `add`, `done`, `update`, `delete` сохраняют обновлённый список задач.
- Поддержаны многострочные задачи, точка с запятой, кавычки и переносы строк.
- Для работы с диском используются `File`, `Directory`, `Path.Combine` и проверки `File.Exists`.
- При повреждённых файлах программа выводит сообщение об ошибке и не перезаписывает данные автоматически.

### Запуск

```bash
cd TodoListApp
dotnet run
```

После первого запуска данные создаются в `TodoListApp/data/`. При повторном запуске профиль и задачи загружаются из этих файлов. Папка `data` находится в `.gitignore` и не загружается в публичный репозиторий.

### Проверка

1. Запустить программу, ввести профиль и создать несколько задач (в том числе многострочную).
2. Отметить одну задачу выполненной, изменить другую и удалить третью.
3. Ввести `exit`, затем повторить `dotnet run`.
4. Убедиться, что профиль не запрашивается повторно, а задачи, статусы и даты восстановились.
5. Открыть `TodoListApp/data/todo.csv` и проверить заголовок CSV и сохранённые строки.
