## Лекция 3: список задач

Программа работает в бесконечном цикле и принимает команды:
- `help` - список команд
- `profile` - имя, фамилия и год рождения пользователя
- `add "текст"` - добавить задачу
- `view` - показать все задачи
- `exit` - завершить программу

Задачи хранятся в массиве `todos` (начальная длина 2). Когда место
заканчивается, создаётся новый массив в 2 раза длиннее, и задачи
копируются в него.

## Лекция 4: 
Консольное приложение на C# для управления персональным списком задач с поддержкой статусов и дат.

## Доступные команды:
- help — вывод списка всех доступных команд.
- profile — вывод данных пользователя (Имя, Фамилия, Год рождения).
- add "текст задачи" — добавление новой задачи (автоматическое расширение массивов в 2 раза при нехватке места).
- view — вывод всех задач с их статусами и датами изменения.
- done <индекс> — отметить задачу как выполненную.
- update <индекс> "новый текст" — обновить текст задачи.
- delete <индекс> — удалить задачу по ее номеру (со сдвигом элементов).
- exit — завершение работы программы.



## Лекция 5:
- **Многострочный ввод (`add --multiline` / `add -m`)**: позволяет вводить объемные задачи по строкам, завершая ввод командой `!end`.
- **Гибкий просмотр (`view [флаги]`)**: поддержка флагов отображения индекса (`-i`), статуса (`-s`), даты (`-d`) или всех данных сразу (`-a`). Длинные тексты автоматически обрезаются до 30 символов.
- **Полное чтение задачи (`read <индекс>`)**: выводит неразрезанный полный текст, статус и актуальную дату изменения задачи.
- **Управление задачами**: команды `done`, `update`, `delete` с синхронным обновлением массивов.

## Лекция 6: Архитектура проекта
- `TodoItem`: класс, инкапсулирующий данные задачи (Text, IsDone, LastUpdate) и методы управления ей (MarkDone, UpdateText, GetShortInfo, GetFullInfo).
- `TodoList`: класс-коллекция, управляющий массивом задач, динамическим расширением памяти и операциями добавления, удаления и поиска.
- `Profile`: класс для работы с данными пользователя и вычисления возраста.

## Доступные команды:
- help — список команд.
- profile — данные профиля и возраст.
- add / add --multiline — добавление задач (обычное или многострочное).
- view [флаги] — табличный просмотр с флагами (-i, -s, -d, -a).
- read <id> — подробный просмотр задачи.
- done <id> — отметить выполненной.
- update <id> "текст" — изменить текст.
- delete <id> — удалить задачу.
- exit — выход.
