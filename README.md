# TodoListApp

Консольное приложение на C# для управления списком задач.  
Работу выполнили: Козлов и Голубев.

- Ввод данных пользователя (имя, фамилия, год рождения) и расчёт возраста.
- Интерактивный режим работы через консольные команды в бесконечном цикле.
- Хранение задач, статусов выполнения (`statuses`) и дат создания/изменения (`dates`) в синхронизированных массивах с автоматическим расширением в 2 раза.
- Полный цикл работы с задачами добавление, просмотр, отметка о выполнении, редактирование текста и удаление со сдвигом элементов.
- Модульная структура каждая команда и служебная логика вынесены в отдельные методы, используются именованные константы.
- Поддержка флагов команд (длинных `--flag`, коротких `-f` и комбинированных `-is`)
- Однострочный и многострочный режимы добавления задач.


Флаги команды `view`

- `--index`, `-i` — показывать индекс задачи;
- `--status`, `-s` — показывать статус задачи;
- `--update-date`, `-d` — показывать дату последнего изменения;
- `--all`, `-a` — показывать все колонки одновременно.
