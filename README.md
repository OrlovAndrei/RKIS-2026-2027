## Занятие 7 - Интерфейсы и паттерн Command

* **Реализован паттерн проектирования Command: создан интерфейс `ICommand` и базовый абстрактный класс `IndexedCommand`**
* **Вся логика команд вынесена из главного файла в отдельные изолированные классы:**
  * `AddCommand` — добавление однострочных и многострочных задач
  * `ViewCommand` — табличный вывод задач с поддержкой флагов
  * `DoneCommand` — отметка задачи выполненной
  * `DeleteCommand` — удаление задачи со сдвигом элементов
  * `UpdateCommand` — изменение текста задачи
  * `ReadCommand` — просмотр полной информации о задаче
  * `ProfileCommand` — вывод данных пользователя
  * `HelpCommand` — вывод справки по командам
  * `ExitCommand` — завершение работы программы
  * `UnknownCommand` — обработка неизвестных команд и ошибок ввода
* **Создан статический парсер `CommandParser` для разбора пользовательского ввода, флагов и создания объектов команд**
* **Главный цикл `Main` упрощён до последовательного вызова парсера и метода `Execute()`**
