
# .:| TodoListApp |:.

## .:| Описание |:.
Консольное приложение на C#.

## .:| Функциональность |:.
- Сохранение имени, фамилии и года рождения пользователя.
- Просмотр профиля пользователя.
- Добавление новых задач.
- Просмотр списка задач.
- Команды управления через консоль.
- Автоматическое увеличение размера массива при заполнении.
- Выход из программы.
- Отметка задач как выполненных.
- Удаление задач по индексу.
- Редактирование текста задач.
- Хранение статуса выполнения каждой задачи.
- Хранение даты создания и последнего изменения.
- Синхронное расширение трех массивов.
- Автоматическое смещение элементов при удалении.
- Разделение логики программы на отдельные методы.

## .:| Команды |:.
- `help` — список команд.
- `profile` — информация о пользователе.
- `add <текст>` — добавление задачи.
- `view` — просмотр задач.
- `exit` — завершение программы.
