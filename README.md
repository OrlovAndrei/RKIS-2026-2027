## Лабораторная работа №2
Создано консольное приложение TodoListApp, добавлен вывод авторов и расчет возраста пользователя.
## Лабораторная работа №3
Добавлены команды:
- help (вывод списка доступных команд)
- profile (вывод информации о пользователе)
- add (добавление новой задачи в массив с автоматическим расширением в 2 раза при заполнении)
- view (отображение нумерованного списка текущих задач)
- exit (корректное завершение работы)
## Лабораторная работа №4
Проведен рефакторинг кода, добавлены новые массивы для хранения статусов и дат. 
Добавлены и обновлены команды:
- add (теперь дополнительно записывает статус "не сделано" и текущую дату)
- view (теперь выводит статус выполнения и дату создания/изменения)
- done (отметка задачи как выполненной со сменой статуса и обновлением даты)
- delete (удаление задачи со сдвигом элементов массива)
- update (обновление текста задачи с записью новой даты)
## Лабораторная работа №5
Реализовано усложнение архитектуры приложения, добавлена поддержка комбинированных флагов форматирования и улучшена отказоустойчивость.
Добавлены и обновлены команды:
- add (реализован многострочный ввод задач по флагам -m или --multiline до ввода стоп-слова !end)
- view (добавлен вывод в виде таблицы с автоматической обрезкой длинного текста до 30 символов и поддержкой комбинированных флагов -i, -s, -d, -a)
- read (добавлено чтение полного текста задачи без обрезки с отображением её текущего статуса и даты изменения)
- help (справочная система полностью обновлена с учетом новых флагов и синтаксиса команд)
Проведен рефакторинг ввода: внедрена безопасная обработка пустых строк и закрытия потока ввода, также проверка года рождения на ввод числа через TryParse.
