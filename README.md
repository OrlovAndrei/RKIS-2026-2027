## Практическое задание — TodoListApp

Консольное приложение для управления списком задач, разработанное на C# с использованием платформы .NET 10.

### Реализованные возможности

- Добавление задач.
- Добавление многострочных задач.
- Просмотр списка задач.
- Отображение номеров, статусов и дат последнего изменения.
- Просмотр полной информации о задаче.
- Изменение текста задачи.
- Отметка задачи как выполненной.
- Удаление задач.
- Создание и просмотр профиля пользователя.

### Команды приложения

| Команда | Описание |
|---|---|
| `add [текст]` | Добавить задачу |
| `add -m` | Добавить многострочную задачу |
| `view` | Показать список задач |
| `view -i` | Показать номера задач |
| `view -s` | Показать статусы |
| `view -d` | Показать даты изменения |
| `view -a` | Показать все данные |
| `read <idx>` | Просмотреть задачу полностью |
| `done <idx>` | Отметить задачу выполненной |
| `update <idx> "текст"` | Изменить текст задачи |
| `delete <idx>` | Удалить задачу |
| `profile` | Показать профиль пользователя |
| `help` | Показать список команд |
| `exit` | Завершить программу |

### Структура проекта

- `Program.cs` — основная программа, обработка команд и взаимодействие с пользователем.
- `TodoItem.cs` — класс отдельной задачи.
- `TodoList.cs` — класс управления списком задач.
- `Profile.cs` — класс профиля пользователя.
