## Описание
Консольное приложение для управления списком задач, разработанное в рамках лабораторных работ. 
В программе реализован личный профиль пользователя, а также полноценный менеджер задач с возможностью добавления, редактирования, удаления и отметки задач как выполненных.
При запуске программа запрашивает имя, фамилию и год рождения пользователя, вычисляет возраст и переходит в режим ввода команд.
## Программа поддерживает следующие команды:
* `help` — выводит список всех доступных команд с кратким описанием.
* `profile` — выводит данные пользователя в формате: <Имя> <Фамилия>, <Год рождения>.
* `add "текст задачи"` — добавляет новую задачу в список. Текст задачи нужно писать в кавычках. 
* `add -m` (или add --multiline) — многострочный режим добавления задачи. Ввод продолжается до тех пор, пока не будет введена строка `!end`.
* `view` — выводит все добавленные задачи (выводятся только непустые элементы). Текст обрезается до 30 символов.
* `view -i` (или --index) — выводит задачи с индексами.
* `view -s` (или --status) — выводит задачи со статусом (сделано/не сделано).
* `view -d` (или --update-date) — выводит задачи с датой последнего изменения.
* `view -a` (или --all) — выводит все данные (индекс, текст, статус, дату). 
* `read` <индекс> — выводит полный текст задачи (без обрезки), её статус и дату последнего изменения.
* `done` <индекс> — отмечает задачу выполненной.
* `delete` <индекс> — удаляет задачу по указанному индексу (все элементы после неё сдвигаются влево).
* `update` <индекс> "новый текст" — обновляет текст задачи (дата изменения обновляется).
* `exit` — завершает цикл и закрывает программу.

## Архитектура (ООП)
Начиная с 6-й лабораторной работы проект переведен на объектно-ориентированный стиль:
* **`TodoItem`** — класс, инкапсулирующий данные одной задачи (текст, статус, дата) и методы работы с ней.
* **`TodoList`** — класс, управляющий массивом задач (добавление, удаление, вывод).
* **`Profile`** — класс для хранения и вывода данных пользователя.
* **`ICommand`** — интерфейс, описывающий контракт для всех команд (метод `Execute()`).
* **Классы команд** (`AddCommand`, `ViewCommand`, `DoneCommand` и т.д.) — реализуют `ICommand`. Каждая команда инкапсулирует свою логику и параметры.
* **`CommandParser`** — статический класс, который разбирает введенную строку, создает нужный объект команды и передает ему зависимости (`TodoList` или `Profile`).
